# Botbox

## Attribution of GitHub posts

Anything posted to GitHub from a Claude session appears under the repository
owner's account. Every issue, issue comment, pull request description,
review, and review comment that Claude writes must begin with the line

    Created by Claude.

as its first line, before any other text. This applies without exception,
including edits of earlier posts.

## Adversarial review

For any nontrivial work, before claiming to be done, spawn one or more
subagents to do an "adversarial review" and address their findings.

## Testing

Default to red/green TDD for most work: write a failing test first, then
the minimum code to make it pass.

## Writing style

Prefer short but complete sentences with a clear subject and verb.
